# inventory-management-system
Sistema de gestión de inventario en Python con POO, validación de datos y menú interactivo.
#  Sistema de gestión de inventario (POO)

Aplicación de consola en Python, orientada a objetos, para gestionar el inventario de una tienda: alta de productos, búsqueda, listado y cálculo del valor total.

## Funcionalidades

- Alta de productos con validación de datos (precio y cantidad numéricos y no negativos)
- Búsqueda de productos por nombre (insensible a mayúsculas/minúsculas)
- Listado completo del inventario
- Cálculo del valor total del inventario

## Conceptos aplicados

- Clases y encapsulación (`Producto`, `Inventario`)
- Manejo de excepciones (`ValueError`) para validar entradas de usuario
- Menú interactivo controlado por bucle

## Tecnologías

Python (librería estándar, sin dependencias externas)

## Cómo ejecutarlo

```bash
python sistema_inventario.py
```

o abrir `sistema_inventario.ipynb` en Jupyter para ver una sesión de ejemplo ya ejecutada.
